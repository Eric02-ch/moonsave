# v1 驗證紀錄

日期：2026-11-18。所有開發操作與畫面測試使用虛構資料，未將私人正式資料上傳至 GitHub。

## 自動化

- 薪資週期邊界、跨年、短月份。
- 支出推估與投資轉出調整、首次缺基準、負推估、帳戶範圍改變。
- 內部轉帳與繳卡費不增加消費；目前餘額須完整確認才回推。
- 前期修改／刪除後，依賴的推估失效，原數字不被靜默改寫。
- 新舊備份、跨期草稿與來源保留。
- 私人同步帳號隔離、CAS 衝突、跨站及大小限制，舊客戶端降版保護。
- 同步讀取忙碌時的儲存會重新排程上傳。
- 本機 HTTP 與原有選用 AI 代理回歸測試；沒有呼叫付費模型。

## 瀏覽器操作

- 完整走完：修改收入與餘額、選擇推估、投資調整、確認頁勾選、正式儲存、閱讀完整報告。案例收入 40,000，帳戶淨額增加 5,000，投資轉出 10,000，得到推估支出 25,000、結餘 15,000。
- 確認儲存後仍標示「含推估」，沒有將確認估值標成實際支出。
- 新增自訂帳戶、轉為信用卡類別、分別設定結帳 20 日及繳款 5 日。
- 改用 HTML dialog 取代瀏覽器原生 prompt/confirm，避免內嵌瀏覽器不支援而無法操作。
- Dashboard 在 360、390、393、430 CSS px 無整頁橫向溢位；設定頁在 360px 與長帳戶名下無整頁橫向溢位。
- 手機尺寸檢查表單與報告；目前是桌面瀏覽器尺寸模擬，未宣稱實體 iPhone Safari 通過。

## 保留限制與下一步

- 實體 iPhone 16 Safari、軟鍵盤、安全區、主畫面安裝及離線需實機驗收。
- 目前餘額回推依使用者完整填入新一期變動，並非銀行自動對帳；月末整理負擔需實際使用回饋。
- 固定發薪日遇短月份採月底；銀行假日提前／延後不自動調整。信用卡日期為設定提示，以帳單為準。
- 舊回報保留在 legacy 備份中，需逐期確認期間後帶入草稿，不直接推定原月份為薪資週期。
- AI 保留入口但未啟用。公開體驗版資料僅存當前瀏覽器，私人版保留原有存取權限。
- 網域沿用現有網址，品牌網域仍未定案。

## 2026-11-19 私人首頁資料銜接修正

- 首頁改用不修改原始資料的讀取模型，納入正式回報、有效草稿與舊版歷史盤點。
- 匯入草稿與其舊來源去重，空白切換草稿不顯示，也不再因切換新建空白草稿。
- 分布圖顯示已提供資產小計，未知卡債或現金不當成 0、不計完整帳戶淨額。
- 目標帳戶即使其他欄位缺漏也可顯示進度，標示日期及資料狀態；單筆資料顯示單點，不補出歷史。
- 舊紀錄與草稿可從首頁開啟資料報告，並保留來源備註及補齊入口；圖表不混接不同口徑。
- 新增 7 項回歸測試，總計 35 項通過；本機以虛構匯入草稿驗證首頁與報告操作。
