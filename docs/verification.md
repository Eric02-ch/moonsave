# v0.1 驗證紀錄

驗證日期：2026-11-18。所有手動操作使用虛構示範資料。

## 自動測試

`npm test` 使用 Node 內建測試，共 12 項。涵蓋：

- 自己帳戶間轉帳不增加現金淨額或回報儲蓄。
- 信用卡預備金只計一次；付款同時減少現金與負債。
- 負的淨儲蓄、零收入、跨年度月份與不同盤點日期。
- 欄位、金額、日期、確認狀態、備份格式與重複月份。
- 建議數量上限、資料不足時不推算。
- 靜態檔案、路徑存取限制、Host 與 Origin 驗證。
- 無金鑰時停用 AI、模擬供應商的請求與回覆、錯誤訊息不洩露內部細節。

`npm run build` 產生可部署的 `dist/`。

## 瀏覽器操作

在桌面與 390 × 844 手機視窗檢查：

- 首次空白頁與載入三個月示範資料。
- 首頁收入、儲蓄、儲蓄率、備用金與信用卡預留資訊。
- 成長紀錄圖表與編輯入口。
- 修改額外儲蓄後重新計算，並在重新載入後保留。
- JSON 備份下載、匯入前確認與成功還原。
- 本機規則月報與未設定 AI 時停用的追問介面。
- 手機底部導覽與首頁沒有水平溢位。
